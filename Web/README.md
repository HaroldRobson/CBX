# CBX.earth Web Application

## Prerequisites
`npm`

## Setup

```sh
npm install -g corepack
corepack enable
```

## Build and host using VSCode

Command Palette > Tasks: Run Build Task (`Shift+Meta+B`)

## Build via CLI

```sh
yarn
yarn landing! build
yarn buyer! build
yarn seller! build
```

## Host via CLI

```sh
yarn landing! start &
yarn buyer! start &
yarn seller! start
```
